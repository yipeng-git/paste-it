# Paste It

[English](README.md) | **中文** | [日本語](README.ja.md) | [한국어](README.ko.md)

面向 macOS 的本地剪贴板管理器 — 视觉时间线、可搜索的历史（含截图里的字），原生体验，不打扰你。

**网站：** [paste-it.app](https://paste-it.app)

![Paste It timeline panel](docs/screenshots/paste-it-history-panel.png)

## 功能

- 可视化时间线，浏览你复制过的内容
- 能搜文本，也能搜截图和图片里的字
- 预览一条，改完再粘贴
- 钉住重要条目（还可放进文件夹）
- Paste Stack：按顺序粘贴多段内容

## 安装

1. 从 [paste-it.app](https://paste-it.app) 或 [GitHub Releases](https://github.com/yipeng-git/paste-it/releases/latest) 下载最新版。
2. 打开 `.dmg`（或解压），把 **Paste It** 拖进 **应用程序**。
3. 从应用程序启动。它会待在菜单栏。
4. 若希望一键粘贴到其他 App，按提示开启 **辅助功能**（系统设置 → 隐私与安全性 → 辅助功能）。

需要 macOS 14 或更高版本。官方构建会在后台自动更新。

## 使用

1. 照常复制 — Paste It 在本机记录历史。
2. 按 **⇧⌘V**（或点菜单栏图标）打开时间线。
3. 点击搜索框（或按 **⌘F**）搜索，也可按类型筛选。选中卡片后，按 **Return**、双击或按 **⌘1…9** 执行主要操作（见下文）。
4. 按 **Space** 在时间线上方预览。点文字可编辑；图片可看 OCR，链接有网页预览。
5. 需要保留的条目可以钉住，或放进自定义文件夹（最多三个）。

### 更多快捷键

| 快捷键 | 作用 |
|--------|------|
| **⇧⌘V** | 打开 / 关闭时间线 |
| **⌘1…9** | 对该卡片执行主要操作 |
| **Return** | 对选中项执行主要操作 |
| **⇧Return** | 按纯文本粘贴 |
| **Space** | 预览 |
| **⌘E** | 编辑选中项 |
| **⇧⌘C** | 打开 Paste Stack |
| **⌃⌘V** | 当前剪贴板按纯文本粘贴一次 |
| **⇧⌘T** | 暂停 / 继续捕获（菜单里） |

**Paste Stack：** 按 **⇧⌘C**，连续复制几段进队列，再在目标 App 里按 **⌘V** 一项项粘贴。顺序（先旧 / 先新）在「设置 → Stack」。

**多选：** **⌘**-点击多张卡片，在直接粘贴模式下按 **Return** 按显示顺序粘贴。所有模式均可用 **⇧Return** 按纯文本粘贴。

单击只选中，不改变剪贴板。**⌘C** 或复制按钮复制一项并保留面板。**设置 → 通用 → 时间线主要操作**提供“直接粘贴”和“仅复制”，统一双击、**Return** 和 **⌘1…9** 的行为。新安装和升级统一默认直接粘贴；主动选择的“仅复制”偏好会保留。**⇧Return** 始终按纯文本粘贴。

直接粘贴需要辅助功能权限。未授权时，单项会先复制，通过操作提示引导返回目标应用按 **⌘V**。写入失败会保留选择并提供重试。多选后按 **⌘C** 会提示选择一项，不再静默只复制首项。

**移除与撤销：**“从历史移除”会保留置顶或文件夹中保存的内容；“取消固定”和“从文件夹移除”只影响对应位置。**菜单 → 撤销移除 / ⌘Z** 可在 **30 秒内**恢复最近移除，当前运行会话最多保留 20 次操作，期间相关附件受到保护。“从所有位置删除”需要确认且无法撤销。批量清理和缩短保留期限会先显示影响数量，并说明是否包含收藏内容；确认批量清理后，之前的移除将无法撤销。

普通移除会显示带“撤销”的 **3 秒 toast**，悬停暂停消失，移开后继续剩余时间；toast 居中悬浮在面板上方 12 pt，不改变主面板布局或抢占键盘焦点。macOS 26+ 使用原生 Liquid Glass，旧系统使用普通材质；短文案采用胶囊，长文案使用两行圆角矩形。“撤销”按钮悬停时高亮、按下时反馈，toast 不叠加额外窗口阴影。toast 消失后，菜单和 **⌘Z** 仍可在原来的 30 秒窗口内撤销。文件夹操作显示具体名称，例如 **从「工作」移除**；**从所有位置删除…** 会打开永久删除确认。

## 隐私

历史只留在这台 Mac — 不用账号，不同步云端。密码管理器等受保护的 pasteboard 类型默认会跳过。可在设置里暂停捕获、忽略 App、限制保留时间。

可选匿名统计（官方构建默认开启）**不会**包含剪贴板内容、OCR、路径或搜索词。随时可在 **设置 → 隐私** 关闭。说明：[`docs/analytics.md`](docs/analytics.md)。

## 给 Agent 用（可选）

Paste It 可开启本地 [MCP](https://modelcontextprotocol.io)，让 Agent 读取和搜索历史。**默认关闭** — 应用运行时在菜单栏打开 **MCP**（`http://127.0.0.1:17321/mcp`）。配置与工具：[`docs/mcp.md`](docs/mcp.md)。
