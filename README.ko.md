# Paste It

[English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | **한국어**

macOS용 로컬 클립보드 매니저 — 시각적 타임라인, 검색 가능한 기록(스크린샷 속 글자 포함), 방해하지 않는 네이티브 사용감.

**웹사이트:** [paste-it.app](https://paste-it.app)

![Paste It timeline panel](docs/screenshots/paste-it-history-panel.png)

## 기능

- 복사한 내용을 시각적 타임라인으로 보기
- 텍스트 검색 — 스크린샷·이미지 안의 글자도 포함
- 미리보고 수정한 뒤 붙여넣기
- 중요한 항목 고정(폴더로도 정리 가능)
- Paste Stack으로 여러 클립을 순서대로 붙여넣기

## 설치

1. [paste-it.app](https://paste-it.app) 또는 [GitHub Releases](https://github.com/yipeng-git/paste-it/releases/latest)에서 최신판 다운로드.
2. `.dmg`를 열거나 압축을 풀고 **Paste It**을 **응용 프로그램**으로 드래그.
3. 응용 프로그램에서 실행. 메뉴 바에 상주합니다.
4. 다른 앱에 한 키로 붙여넣으려면 안내에 따라 **손쉬운 사용**을 허용(시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용).

macOS 14 이상. 공식 빌드는 백그라운드에서 자동 업데이트됩니다.

## 사용법

1. 평소처럼 복사 — Paste It이 로컬에 기록을 남깁니다.
2. **⇧⌘V**(또는 메뉴 바 아이콘)로 타임라인 열기.
3. 검색창을 클릭하거나 **⌘F**를 눌러 검색하고 유형으로 필터링합니다. 카드를 선택한 후 **Return**, 더블 클릭 또는 **⌘1…9**로 기본 동작을 실행합니다 (아래 설명 참조).
4. **Space**로 타임라인 위 미리보기. 텍스트를 클릭해 편집. 이미지는 OCR, 링크는 페이지 미리보기.
5. 남길 항목은 고정하거나 커스텀 폴더에 넣기(최대 3개).

### 더 많은 단축키

| 단축키 | 동작 |
|--------|------|
| **⇧⌘V** | 타임라인 열기 / 닫기 |
| **⌘1…9** | 해당 카드의 기본 동작 |
| **Return** | 선택 항목의 기본 동작 |
| **⇧Return** | 일반 텍스트로 붙여넣기 |
| **Space** | 미리보기 |
| **⌘E** | 선택한 클립 편집 |
| **⇧⌘C** | Paste Stack 열기 |
| **⌃⌘V** | 현재 클립보드를 한 번만 일반 텍스트로 붙여넣기 |
| **⇧⌘T** | 캡처 일시 중지 / 재개(메뉴에서) |

**Paste Stack:** **⇧⌘C**로 연 뒤 여러 번 복사해 큐에 넣고, 대상 앱에서 **⌘V**로 하나씩 붙여넣기. 순서(오래된 것 / 최신 것 먼저)는 설정 → Stack.

**다중 선택:** **⌘**-클릭으로 여러 항목을 선택한 후 바로 붙여넣기 모드에서 **Return**으로 표시 순서대로 붙여넣습니다. 모든 모드에서 **⇧Return**으로 일반 텍스트를 붙여넣을 수 있습니다.

한 번 클릭하면 선택만 하며 클립보드는 변경하지 않습니다. **⌘C** 또는 복사 버튼은 항목 하나를 복사하고 패널을 유지합니다. **설정 → 일반 → 타임라인 기본 동작**에서 바로 붙여넣기 또는 복사만을 선택하면 더블 클릭, **Return**, **⌘1…9**가 같은 동작을 합니다. 새 설치와 업그레이드 모두 바로 붙여넣기가 기본입니다. 사용자가 선택한 복사만 설정은 유지합니다. **⇧Return**은 항상 일반 텍스트로 붙여넣습니다.

바로 붙여넣기에는 손쉬운 사용 권한이 필요합니다. 권한이 없으면 항목 하나를 복사하고 대화상자에 대상 앱으로 돌아가 **⌘V**를 누르라는 안내를 표시합니다. 쓰기 실패 시 선택을 유지하고 다시 시도할 수 있습니다. 다중 선택 후 **⌘C**를 누르면 첫 항목만 조용히 복사하지 않고 항목 하나를 선택하도록 안내합니다.

**제거와 실행 취소:** 기록에서 제거해도 고정이나 폴더에 저장한 내용은 유지됩니다. 고정 해제와 폴더에서 제거는 해당 위치에만 적용됩니다. **메뉴 → 제거 실행 취소 / ⌘Z**로 **30초 이내**의 제거를 현재 실행 세션에서 최대 20회 복원하며, 이 기간에는 첨부 파일을 보호합니다. 모든 위치에서 삭제는 확인이 필요하고 실행 취소할 수 없습니다. 일괄 정리와 보관 기간 단축은 먼저 대상 수와 저장 항목 포함 여부를 보여줍니다. 일괄 정리를 확정하면 이전 제거의 실행 취소가 종료됩니다.

일반 제거 후에는 **실행 취소 버튼이 있는 3초 토스트**가 표시됩니다. 포인터를 올리면 타이머가 멈추고, 벗어나면 남은 시간이 이어집니다. 토스트는 패널 위 12pt에 중앙 정렬로 표시되며 레이아웃과 키보드 포커스를 바꾸지 않습니다. macOS 26 이상은 네이티브 Liquid Glass, 이전 버전은 표준 소재를 사용합니다. 짧은 문구는 캡슐, 긴 문구는 두 줄의 둥근 사각형으로 표시됩니다. 실행 취소 버튼은 호버 시 강조되고 누르면 시각적으로 반응하며, 별도의 창 그림자는 추가하지 않습니다. 토스트가 사라진 뒤에도 원래 30초 기한 안에는 메뉴와 **⌘Z**로 실행 취소할 수 있습니다. 폴더 작업은 **“업무”에서 제거**처럼 이름을 표시합니다. **모든 위치에서 삭제…**는 영구 삭제 확인을 엽니다.

설정은 접기 버튼 없이 항상 표시되는 네이티브 사이드바를 사용하며 처음에는 **일반**을 표시합니다. 시스템 설정처럼 사이드바가 제목 표시줄까지 이어지며 컬러 아이콘과 간결한 행을 사용합니다. 버전 정보는 **정보**에 있습니다. 일반에서는 바로 붙여넣기를 선택하고 손쉬운 사용 권한이 없을 때만 안내를 표시합니다. 권한 상태는 **개인정보**에서 확인할 수 있습니다. **클립보드**에서 캡처, 보관 기간, 기록 수 제한을 관리하고 폴링 간격은 **고급 설정**에 있습니다. **개인정보**에도 시스템 권한 항목이 있으며 정리는 **저장 공간**에서 할 수 있습니다. macOS 26에서는 시스템 네이티브 Liquid Glass 사이드바를, 이전 버전에서는 표준 시스템 스타일을 사용합니다. 창 크기와 위치를 기억합니다.

## 개인정보

기록은 이 Mac에만 — 계정 없음, 클라우드 동기화 없음. 비밀번호 관리자 등 보호된 pasteboard 유형은 기본적으로 건너뜁니다. 설정에서 캡처 일시 중지, 앱 무시, 보관 기간 제한이 가능합니다.

선택적 익명 통계(공식 빌드에서는 켜짐)에는 클립보드 내용, OCR, 경로, 검색어가 **포함되지 않습니다**. **설정 → 개인정보**에서 언제든 끌 수 있습니다. 자세한 내용: [`docs/analytics.md`](docs/analytics.md).

## 에이전트용(선택)

로컬 [MCP](https://modelcontextprotocol.io) 서버로 에이전트가 기록을 읽고 검색할 수 있습니다. **기본 꺼짐** — 앱 실행 중 메뉴 바에서 **MCP** 켜기(`http://127.0.0.1:17321/mcp`). 설정과 도구: [`docs/mcp.md`](docs/mcp.md).
